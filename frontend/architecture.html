Hybrid search

Each chunk has a dense vector (meaning) and a BM25 sparse vector (exact words such as "FDsys" or "58 percent"). Both rankings are merged with Reciprocal Rank Fusion, which uses ranks only, so no score scaling is needed.

Cross-encoder rerank

Top 20 hybrid hits are re-scored by reading question and passage together (MiniLM), keeping the best 5 to 8.

Sentence-aware chunking

Chunks end on sentence boundaries with a small overlap. On the GPO report this cut 167 naive chunks to 83, with 85% ending at a sentence end.

Parent / child chunks

~280-token children are searched; the ~900-token parent section is what the LLM reads, so answers keep their surrounding context.

Heading-path embedding

The chapter and section path is prepended to the text that is embedded; the stored text is unchanged.

Query routing & filters

One LLM call extracts region (for example Pakistan maps to MNA), chapter (only if the question says "Chapter N"), executive summary and box, and rewrites the search query. Rules take over if the call fails. Header, references and table-of-contents chunks are always excluded.

PDF text repair

Fixes ligature glyphs, the dropped "Th" ligature (Te to The), line-break hyphens, and two-column reading order.

Table rebuild

Tables are rebuilt from their dark header bars into "Table: … Column: …" plus "label: value" rows, including the multi-level header of the energy table.

Footnote linking

Superscripts become markers like [^7]. A chunk containing a marker gets "[Note 7] …" appended, and each endnote is also its own chunk.

Chart vision

Each visual page is sent once to Gemini; the description (for example 445 kg baseline, –99 kg reductions, 346 kg total) is indexed and cached in data/cache.

Grounded answers

Passages are numbered with their pages. The model must cite like [1], or reply exactly "I could not find this in the document."
